# Hybrid-IAM-Lab
This project documents the design, implementation, and administration of a hybrid Identity and Access Management (IAM) environment built in a home lab using Microsoft technologies. My experience outside of this includes 2+ years doing IT Support for a public school district working at multiple different schools in the same year managing thousands of computers and user accounts through Active Directory and Entra ID. I have experience with Microsoft Admin Center, Intune/Intune Education, Entra, and Azure. I have used them all to help manage groups, users, MFA, policies, and registered and hybrid-joined devices. With that comes experience autopiloting and imaging new devices and reimaging old devices that need OS updates or those that have fallen out of policy.
